# 픽셀 행렬 실험실

0~255 명암의 픽셀 그림을 그리고, 거기에 행렬을 곱해 그림이 어떻게 바뀌는지
직접 확인하는 고등학교 수학 실습 도구입니다.

핵심 아이디어는 **모든 변환을 그림 행렬의 좌·우에 곱하는 n×n 행렬로 나타내는 것**입니다.

```
결과 = L · A · R
```

| 변환 | n×n 표현 |
|---|---|
| 상하 반전 | `J·A` |
| 좌우 반전 | `A·J` |
| y=x 대칭 | `J·Aᵀ·J` |
| 90°·180°·270° 회전 | 위 셋의 조합 |
| 확대·축소 | `S·A·Sᵀ` |
| 기본행연산 | `E·A` (기본행렬) |
| 되돌리기 | `L⁻¹ · 결과 · R⁻¹` |

45°처럼 90°의 배수가 아닌 회전은 행과 열이 섞이므로 원리상 `L·A·R` 꼴로 쓸 수 없습니다.
이 경우 좌표 2×2 변환으로 계산하고, 화면에 그 사실을 표시한 뒤 그 지점을 새 기준으로 삼습니다.

---

## 학생 활동 흐름

1. **그림 그리기** — 격자에 0~255 값을 칠해 행렬 A를 만든다
2. **목표 적기** — 그림을 어떻게 바꾸고 싶은지 문장으로 쓴다
3. **연산 쌓기** — 연산을 고르면 오른쪽에 결과가 즉시 나타난다
4. **제출하기** — `(   )를 만들고 싶었다. 그래서 (   )를 계산했더니 (   )가 나왔다.`

## GitHub Pages 배포

빌드 과정이 없는 정적 사이트라서 파일을 그대로 올리면 됩니다.

```bash
git init
git add .
git commit -m "픽셀 행렬 실험실"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

그다음 저장소의 **Settings → Pages** 에서

- Source: `Deploy from a branch`
- Branch: `main` / `/ (root)`

를 고르면 잠시 뒤 `https://<계정>.github.io/<저장소>/` 로 열립니다.

### 로컬에서 확인할 때

ES 모듈을 쓰기 때문에 `index.html` 을 더블클릭해서 여는 방식(`file://`)으로는
동작하지 않습니다. 브라우저가 모듈 파일 불러오기를 막기 때문입니다.
아래처럼 간단한 서버를 띄우고 `http://localhost:8000` 으로 접속하세요.

```bash
python3 -m http.server 8000
```

## 파일 구조

```
index.html          화면 구조(마크업)만 담당
css/style.css       전체 스타일
js/
├─ state.js         모든 모듈이 공유하는 상태와 상수
├─ matrix.js        순수 행렬 계산 (곱셈, 역행렬, 전치 …)
├─ transforms.js    선형변환 → n×n 좌·우 곱 분해
├─ ops.js           연산 종류 목록과 기본값
├─ pipeline.js      연산을 순서대로 적용하며 L·A·R 유지
├─ render.js        색 계산, 격자·행렬 그리기
├─ strip.js         연산 카드 그리기
├─ examples.js      예시 그림
├─ submit.js        제출문 · JSON · 서버 저장 자리
└─ app.js           시작점, 이벤트 연결
```

새 연산을 추가하려면 `ops.js` 에 항목을 넣고, `pipeline.js` 에 계산을,
`strip.js` 에 입력칸을 더하면 됩니다.

## DB 연동

지금은 JSON 파일 내려받기까지만 되어 있습니다. 서버가 준비되면
`js/submit.js` 의 `saveToServer()` 안에 있는 `fetch` 주석을 풀고 주소만 바꾸면 됩니다.

내보내는 데이터에는 다음이 들어 있습니다.

```jsonc
{
  "n": 8,
  "matrixA": [[...]],          // 학생이 그린 그림
  "matrixB": [[...]],
  "steps": [ ... ],            // 쌓은 연산 목록 (재현 가능)
  "expression": "P2·J·(A)ᵀ·J·Q1",
  "composite": { "left": [[...]], "right": [[...]], "transposed": false, "base": "A" },
  "result": [[...]],
  "resultClipped": [[...]],    // 0~255로 자른 값
  "goal": "...", "outcome": "...",
  "sentence": "(...)를 만들고 싶었다. 그래서 (...)를 계산했더니 (...)가 나왔다."
}
```

브라우저 콘솔에서 `PixelMatrixLab.getSubmission()` 으로도 같은 데이터를 꺼낼 수 있습니다.
